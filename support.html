SUPPORT

Let’s get your view back.

Check these common fixes, or send a reproducible issue with the details below.

Report an issue ↗Browse known issues

Controls are unavailable

Check USB connection, target firmware and your fixed setup. Turn tracking off, leave the camera stationary and confirm the reference in Settings. A reconnect, fault or update requires confirmation; Stream Deck cannot do this for you. If the position is outside the native control range, use the camera’s joystick to move inward before retrying.

The preview is missing

Select the physical camera in OBS and start OBS Virtual Camera. Choose that virtual source in Osmo Webcam and enable preview. Check macOS camera permission for Osmo Webcam. Keep the direct USB video source in OBS.

A Stream Deck button does nothing

Keep the desktop app running, confirm/Arm the correct setup, and check the plugin’s pairing status. A slot with no saved preset is intentionally a no-op. A pinned preset ID must belong to the configured camera/setup. After revoking a client, create and pair a new dedicated Control token.

For HTTP actions, check that the optional bridge is running and use the method, URL and header shown in the app’s Integrations guide. These credentials differ from direct API client tokens.

An update was interrupted

Open the installed app and follow recovery. Preserve saved state and local diagnostics. Do not delete lock files or replace app bundles while recovery is running. If recovery cannot continue, report its visible error code.

What to include in a report

  • App and plugin versions, macOS version and Mac architecture.
  • Camera model and firmware version, checked on the camera.
  • The steps taken, expected result, actual result and visible error code.
  • A cropped screenshot if it helps explain the problem.
Issues are public.

Remove tokens, HTTP keys, USB identifiers, personal setup names, private recordings and unrelated screen content. Reveal Diagnostics opens local files; it does not upload them. Review and redact any excerpt yourself.

Preview scope

The first preview targets Apple Silicon, macOS 26+ and standard Pocket 4 firmware 01.03.14.04. Battery telemetry and additional platforms are not included. Arrival, immediate physical stop, wider-range behavior and release qualification have limits; consult the notes attached to the exact release you install.
