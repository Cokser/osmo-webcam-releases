SETUP GUIDE

Start with a clear view.

Connect your camera, confirm a fixed setup, then save the views you use.

Public downloads are not available yet.

This guide describes the intended public-preview workflow. Get release availability from the downloads page; check each release’s compatibility notes before installing.

1. Install the desktop app

When a public installer is available, download the DMG from the official releases page. Open Osmo Webcam and choose Install for This User. The app installs in ~/Applications/Osmo Webcam.app. Subsequent updates use App Updates → Update & Restart.

If you have the earlier Pocket Control development app, quit it and move its app bundle to Trash before running the new installer. Keep your private data folders intact. Existing presets and credentials use the same storage.

2. Connect USB video and preview

  1. Connect a standard Pocket 4 by USB in webcam mode. The first preview targets Apple Silicon, macOS 26+ and firmware 01.03.14.04.
  2. Keep the physical camera selected in OBS. Start OBS Virtual Camera.
  3. Select OBS Virtual Camera in Osmo Webcam and enable preview. Grant macOS camera permission for the local preview when requested.

3. Confirm the fixed setup

  1. Open Settings and disconnect control before configuring the camera.
  2. Select the discovered device, enter the firmware checked on the camera, and name your fixed setup.
  3. Review a clear pan/tilt window for your mount. Saving a setup does not start movement.
  4. Turn tracking off, leave the camera stationary, confirm its reference and Arm. New setups use the conservative profile; faster experimental profiles require review.

Keep a clear path throughout the selected window. Reported positions do not prove physical clearance, arrival or immediate stop.

4. Save your first preset

Set the view and raw zoom, then choose the always-first Add Preset card. Enter a name and transition. Each camera can hold twenty presets. Recall returns to a saved view; selecting another preset replaces an ongoing transition.

Stream Deck

  1. Use Stream Deck 6.6 or later. Once released, install the compatible companion .streamDeckPlugin from official downloads or the app’s bundled installer.
  2. Open Osmo Webcam → Integrations → Stream Deck. Create a dedicated Control token and choose Copy token.
  3. Paste it once into an Osmo Webcam action’s property inspector and choose Pair. Tokens are stored outside shared action/profile settings.
  4. Add Recall Preset actions. Bind a preset by ID to follow it through reordering, or use slots 1–20 to follow collection order. Empty slots do nothing.
  5. Add Stop, Pan / Tilt, Zoom or reviewed Recenter actions. Hold movement keys and release to stop scheduling. The plugin cannot Arm the camera.

Revoke the client in the app to remove access. Forget token removes the plugin’s local credential. The plugin’s direct installer is updated separately from the app.

Other local software

Open Integrations → HTTP requests for copy buttons covering request URLs, method, headers, bodies and complete curl examples. The optional local HTTP bridge exposes twenty preset slots and handles the recall lease. It is a separate service; opening the guide does not install or start it.

For direct API v1 access, the guide can create a named client and copy status, preset and Stop examples. Readiness, reference checks and motion leases still apply. Keep credentials private; never put them in a URL or shared profile.

Updates, recovery and quitting

The app can check and download updates automatically. Installing requires Update & Restart. Updates preserve saved state and reopen disarmed. If installation is interrupted, reopen the installed app and follow recovery; do not start extra app copies or remove lock files.

Setup memory is optional. It applies after a clean Quit with the same USB session, fixed setup and app build. Reconnects, faults and updates require confirmation. Interrupted movement is never replayed.

Closing the window leaves the local agent running. Choose Quit Osmo Webcam to stop the agent. Get help with setup or recovery →
