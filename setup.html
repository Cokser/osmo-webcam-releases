SETUP GUIDE

Start with a clear view.

Connect your camera, confirm a fixed setup, then save the presets you use.

A public preview is available.

This guide describes the public-preview workflow. Get release availability from the downloads page; check each release’s compatibility notes before installing.

1. Install the desktop app

When a public installer is available, download the DMG from the official releases page. Open Osmo Webcam and choose Install for This User. The app installs in ~/Applications/Osmo Webcam.app. Subsequent updates use About → Update & Restart.

If you have the earlier Pocket Control development app, quit it and move its app bundle to Trash before running the new installer. Keep your private data folders intact. Existing presets and credentials use the same storage.

2. Connect USB and choose a preview

  1. Connect a standard Pocket 4 by USB in webcam mode. The preview targets Apple Silicon, macOS 26+ and firmware 01.03.14.04.
  2. Open Settings → Camera and connect the discovered camera. Controls work independently of OBS and preview.
  3. For preview without OBS, select Pocket camera · USB and choose Enable Preview. Allow macOS camera access when requested.
  4. If OBS is capturing the camera, start OBS Virtual Camera and select that source in Osmo Webcam instead. If macOS reports the Pocket as in use, release the other capture or choose OBS Virtual Camera.

Preview is off until enabled. Disconnect stops preview and clears the image; reconnect leaves it off. Preview does not record or upload video.

3. Confirm the fixed setup

  1. In Settings → Camera, use Advanced camera settings to configure or edit your setup. Disconnect control before editing it.
  2. Select the discovered device, enter the firmware checked on the camera, name the fixed setup and review a clear pan/tilt window.
  3. Save the setup, keep the camera fixed and stationary with tracking off, then choose Confirm setup when shown. Saving alone does not start movement.
  4. A valid confirmation is remembered by default for normal Quit/restart with the same camera session and setup. Advanced settings provides an opt-out. Reconnects, faults and app updates require confirmation again.

Keep a clear path throughout the selected window. Faster experimental motion profiles require review. Reported positions do not prove physical clearance, arrival or immediate stop.

4. Save your first preset

Choose the always-first Add Preset card to capture the current framing, then enter a name and transition. Each camera can hold twenty presets. The preset editor offers separate pan/tilt and zoom speeds, or you can inherit the app defaults. Selecting another preset replaces an ongoing recall.

Click a card or list item to show its details. Open Preset tools → Export to save a JSON backup, or Import to review an existing export before applying it. Press Escape in the app to cancel movement scheduling.

Stream Deck

  1. Use Stream Deck 6.6 or later. Open Osmo Webcam → Integrations → Stream Deck and choose Install Stream Deck plugin. The app provisions its dedicated local Control credential before opening the bundled installer.
  2. If you installed the plugin from official downloads separately, choose Connect Stream Deck in the app once. No token entry is needed in Stream Deck.
  3. Add an Osmo Webcam Recall Preset action and choose the actual preset name from its dropdown. The binding follows that preset through renaming and reordering. Deleted presets do not fall back to another view.
  4. Add Pan / Tilt or Zoom actions and choose a direction. Hold to move and release to stop scheduling. These controls can overlap. Recenter uses the guarded USB default; a separate Stop key is optional for cancelling recalls or held controls.

The plugin cannot confirm setup or Arm the camera. Revoke access in Settings → Integrations → Client access. After revocation, choose Connect Stream Deck explicitly to pair again. Credentials stay outside shared action/profile settings. Update the plugin separately using its compatible direct installer.

Other local software

Open Integrations → HTTP requests for copy buttons covering request URLs, method, headers, bodies and complete curl examples. The optional local HTTP bridge exposes twenty preset slots and handles the recall lease. It is a separate service; opening the guide does not install or start it.

For direct API v1 access, the guide can create a named client and copy status, preset and Stop examples. Readiness, reference checks and motion leases still apply. Keep credentials private; never put them in a URL or shared profile.

Updates, recovery and quitting

The app can check and download updates automatically. Installing requires Update & Restart. Updates preserve saved state and reopen disarmed. If installation is interrupted, reopen the installed app and follow recovery; do not start extra app copies or remove lock files.

Valid setup confirmation is remembered by default, with an opt-out in Advanced camera settings. It applies after a clean Quit with the same USB session, fixed setup and app build. Reconnects, faults and updates require confirmation. Interrupted movement is never replayed.

Closing the window leaves the local agent running. Choose Quit Osmo Webcam to stop the agent. Get help with setup or recovery →
