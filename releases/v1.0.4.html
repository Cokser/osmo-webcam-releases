RELEASE NOTES

Release 1.0.4

Build 45 · Stream Deck plugin 0.2.5 · API v1

New in 1.0.4

Separate Quality and FPS selectors list the resolutions, pixel formats and frame rates advertised by the selected preview source, including portrait modes and native 4K when available. Received dimensions and frame rate appear in the preview status. Rapid changes apply the latest choice after a one-second settling interval.

With Preview off, Quality and FPS are read-only and follow the capture configuration reported by macOS. Enabling Preview inherits that configuration. Ready pan, tilt, zoom and preset recall remain available independently of preview. OBS Virtual Camera can also preview without a Pocket USB control connection.

Hold A/D to pan left/right, W/S to tilt up/down, Q/E/Z/X for upper-left, upper-right, lower-left and lower-right, and ↑/↓ to zoom in/out. Release to stop scheduling; Escape or app focus loss cancels input. Shortcuts work while the main app is focused, outside fields and dialogs. Simultaneous PTZ uses one input stream and releases each component independently where supported.

The tested Pocket 4 USB modes expose 24/25/30 FPS, including 3840×2160 near 30 FPS. The camera’s on-screen 48/50/60 FPS recording choices are separate from USB capture; this release does not advertise 60 FPS Pocket USB output. Existing presets, settings, camera limits and Stream Deck pairing are preserved. Motion guards and API v1 remain unchanged; Stream Deck plugin 0.2.5 remains compatible.

USB controls and preview

Control Pocket 4 pan, tilt and zoom without OBS. Enable Pocket camera · USB for direct local preview, or choose optional OBS Virtual Camera when using OBS. Preview starts explicitly. Disconnect stops capture and clears the image; reconnect leaves it off. Osmo Webcam does not record or upload preview video.

Presets and motion

Save twenty presets per camera with the first Add Preset card. Each preset can choose a transition and separate pan/tilt and zoom speeds. A new recall replaces an ongoing transition. Pan/tilt and zoom can overlap, and held components release independently. Reviewed setups can use 1×–4× zoom; the default uses small steps at 15 raw units/s. Fast 32 is available only with a compatible reviewed profile; requested pacing is not a measured motor speed.

Stream Deck

Use Install Stream Deck plugin or Connect Stream Deck in the app for automatic local pairing. The Recall Preset inspector has one dropdown of actual presets; no token entry is needed. Hold Pan / Tilt or Zoom to move, release to stop scheduling, and use guarded Recenter directly. A Stop key is optional. Camera readiness is managed by the app. Revoke client access in Settings → Integrations and explicitly connect again to re-pair.

Settings, updates and recovery

About shows the installed version and build, project/privacy/support links, copyable app information and update controls.

Settings and Preset tools use compact tabs, cards and contextual hints. Camera controls prepare automatically when you connect, restart or reconnect. There are no setup names or confirmation checkboxes. Press Escape in the app to cancel movement scheduling.

Signed updates install with Update & Restart. Interrupted-update recovery checks the installed app and saved state before reopening and preparing controls. Movement is never replayed. The plugin uses its compatible direct installer separately.

Compatibility and limitations

Apple Silicon · macOS 26+ · standard Osmo Pocket 4 firmware 01.03.14.04. Stream Deck 6.6+ is optional. Validation covers one Mac and an existing macOS account; clean-account and second-Mac installation remain unqualified. Intel, Windows, Linux, other cameras and other firmware are outside this release.

DJI ActiveTrack control and battery telemetry are not included. Use camera controls with tracking off and clear travel. Physical arrival and immediate stop are not guaranteed by readback or completed requests. A finite command accepted by the camera may finish after scheduling stops. Wider-range recovery, full-travel behavior and extended source continuity remain experimental.
