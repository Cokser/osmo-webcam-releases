RELEASE NOTES

Release 1.1.0

Build 46 · Stream Deck plugin 0.2.5 · API v1

New in 1.1.0

Optional Mac face tracking uses Apple Vision on the selected live preview and steers the Pocket through the existing USB motion engine. Enable Preview, then use the face-frame icon and Tracking Off / Tracking On toggle. The largest detected face is selected first. Turn DJI’s built-in ActiveTrack off on the camera.

Presets now save Mac face tracking On or Off. Add Preset and Update capture the current state; editing, duplicate and JSON export/import preserve it. Existing presets default to Off without changing saved framing. A successful recall can start tracking afterward only while the desktop preview is visible, receiving and the camera is ready. This works with app, Stream Deck and API recalls. It never turns preview on automatically.

Manual movement, an Off preset, Escape, target loss and interrupted capture or control stop tracking. Valid manual and preset commands take priority. Source/quality changes, disconnect, hide/minimize and Quit leave tracking off; old movement and completed recalls are not replayed. A continuous movement execution retains its existing 85-second budget.

The preview footer groups compact Source, Quality and FPS controls on the left, with the icon-led tracking toggle and status on the right. On is highlighted in blue; custom FPS stays with the quality controls.

Face detection runs locally; no images or face positions are recorded or uploaded. Requested tracking motion is capped at 6°/s through the selected bounded profile, with the existing leases, travel windows and native guards. This is experimental host face following, with a confined direct-USB review on one Mac. Full-window following, tracking with zoom/portrait variants and the OBS tracking path remain unqualified. It is not native DJI ActiveTrack control.

USB controls and preview

Control Pocket 4 pan, tilt and zoom without OBS. Enable Pocket camera · USB for direct local preview, or choose optional OBS Virtual Camera when using OBS. Preview starts explicitly. Disconnect stops capture and clears the image; reconnect leaves it off. Osmo Webcam does not record or upload preview video.

Presets and motion

Save twenty presets per camera with the first Add Preset card. Each preset can choose a transition and separate pan/tilt and zoom speeds. A new recall replaces an ongoing transition. Pan/tilt and zoom can overlap, and held components release independently. Reviewed setups can use 1×–4× zoom; the default uses small steps at 15 raw units/s. Fast 32 is available only with a compatible reviewed profile; requested pacing is not a measured motor speed.

Stream Deck

Use Install Stream Deck plugin or Connect Stream Deck in the app for automatic local pairing. The Recall Preset inspector has one dropdown of actual presets; no token entry is needed. Hold Pan / Tilt or Zoom to move, release to stop scheduling, and use guarded Recenter directly. A Stop key is optional. Camera readiness is managed by the app. Revoke client access in Settings → Integrations and explicitly connect again to re-pair.

Settings, updates and recovery

About shows the installed version and build, project/privacy/support links, copyable app information and update controls.

Settings and Preset tools use compact tabs, cards and contextual hints. Camera controls prepare automatically when you connect, restart or reconnect. There are no setup names or confirmation checkboxes. Press Escape in the app to cancel movement scheduling.

Signed updates install with Update & Restart. Interrupted-update recovery checks the installed app and saved state before reopening and preparing controls. Movement is never replayed. The plugin uses its compatible direct installer separately.

Compatibility and limitations

Apple Silicon · macOS 26+ · standard Osmo Pocket 4 firmware 01.03.14.04. Stream Deck 6.6+ is optional. Validation covers one Mac and an existing macOS account; clean-account and second-Mac installation remain unqualified. Intel, Windows, Linux, other cameras and other firmware are outside this release.

Native DJI ActiveTrack control and battery telemetry are not included. Keep DJI ActiveTrack off on the camera, including while using optional Mac face tracking, and keep travel clear. Mac tracking follows the selected preview; OBS must show the controlled Pocket’s full, unmirrored image. A single face is associated by position, not identity. Physical arrival and immediate stop are not guaranteed by readback or completed requests. A finite command accepted by the camera may finish after scheduling stops. Wider-range recovery, full-travel behavior and extended source continuity remain experimental.
