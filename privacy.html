PRIVACY

Your presets stay local.

No app account, cloud preset storage, advertising or automatic telemetry/crash uploads.

Local settings and credentials

Camera/setup identifiers, presets, settings, API client records and bounded diagnostics are stored in your macOS user account. The Stream Deck plugin talks to the loopback API on the same Mac. Its dedicated token is stored in an owner-only credential file, outside action settings and shared profiles.

Install/Connect Stream Deck in the app provisions a dedicated Control-only credential for the plugin. No token is entered in its inspector, and the plugin does not read the desktop administrator credential. Revoke the client in Settings → Integrations → Client access to remove access. Pairing again requires an explicit Connect/Install action in the app.

Camera preview

You can explicitly enable direct Pocket USB preview without OBS or select OBS Virtual Camera as an optional source. macOS camera permission is used for preview. Frames are displayed locally; Osmo Webcam does not record or upload them and does not use microphone or screen-capture access. Disconnect stops preview and clears the image. Reconnect does not restart capture.

Updates and this website

Update checks contact GitHub Pages. Downloads contact GitHub and its asset hosts. These services receive normal network metadata, such as IP address. macOS may contact Apple for code-signing or notarization checks. Automatic app update checks/downloads can be disabled in About.

This site is hosted on GitHub Pages. It has no added analytics, advertising, third-party fonts or tracking scripts.

Diagnostics and support

Reveal Diagnostics opens local logs and sends nothing. Review files before sharing excerpts: logs can contain device identifiers, paths and setup names. Public GitHub issue reports are public. Do not post credentials or raw diagnostic folders.

Deleting local data

Removing the app does not erase saved state. For compatibility with earlier installations, data remains under ~/Library/Application Support/Pocket Control/, logs under ~/Library/Logs/Pocket Control/ and update downloads under ~/Library/Caches/Pocket Control/. Plugin credentials use the StreamDeckPlugin subfolder in Application Support.

Quit Osmo Webcam, Stream Deck and any optional HTTP bridge before intentionally removing those folders. This erases the associated presets, settings and credentials; keep a backup if you need them.
